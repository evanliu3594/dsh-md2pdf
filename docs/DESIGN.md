# 设计方案

本文记录 dsh-md2pdf 的确定设计：架构、数据结构、交互语义与边界。实现以本文为准；改动设计与实现同步进行。

## 目标与范围

插件解决一件事：把 DeepSeek Harness 侧边栏里打开的 Markdown 变成一份可直接打印或分发的 PDF。

范围边界：

- 只处理文件标签中的 Markdown。聊天里渲染的 Markdown 不在范围内。
- PDF 写在源文件同目录，同名覆盖。
- 版式由用户可管理的预设决定，预设是可编辑的 CSS 文件。
- 渲染与打印不依赖本机安装的 pandoc、LaTeX 或其它命令行工具。

## 架构

插件分两半，各自独立加载。

Host 半（`index.js` + `src/`）运行在 Node 环境，负责路由、渲染、打印、预设存取与模型工具。

Client 半（`client.js`）是浏览器经典脚本，通过 `window.__ModuleLoader__` 载入，模块 id 必须等于包名。它只负责界面：右键菜单项、文件标签工具栏按钮、设置页、提示。

| 模块 | 职责 |
|---|---|
| `src/markdown.js` | 内置 Markdown 渲染器 |
| `src/math.js` | temml 懒加载与降级 |
| `src/themes.js` | 三个内置预设的样式文本与名称 |
| `src/presets.js` | 预设库：播种、迁移、增删改排、动作分发 |
| `src/opener.js` | 用系统默认程序打开文件 |
| `src/previews.js` | 设置页缩略图与页面边距回读 |
| `src/settings.js` | 用户目录解析与样式上限 |
| `src/document.js` | 纸质 HTML 模板与结构样式表 |
| `src/html-build.js` | 正文生成与文档组装 |
| `src/export.js` | 导出编排与能力上报 |
| `src/pdf.js` | 打印器发现、无头打印、落盘等待 |
| `src/proc.js` | PATH 查找与子进程执行 |

## 预设库

### 模型

一份预设由三样东西组成：标识、显示名、一份 CSS 文本。

标识一经生成不再改变，决定文件名。显示名可以改。CSS 是该预设的完整覆盖层，不继承其它预设。

内置三个预设：`lark`、`gongwen`、`paper`。它们与用户新建的预设地位相同，都可编辑、可删除，区别只有两点：删空后重建的是默认预设 `lark`，以及编辑器中提供「恢复内置预设」补回缺失项。

### 文件布局

```
$DSH_HOME/md2pdf/
  presets.json          { version, selected, presets: [{ id, name }] }
  presets/<id>.css      该预设的样式
```

`presets.json` 是权威。数组顺序即卡片顺序，`selected` 记当前使用的预设。

写入顺序固定：先写 CSS 文件，再写索引。中断最多留下一个没人引用的 CSS 文件；不会出现条目指向不存在的样式。

索引写入用「写 `.tmp` 再改名」，避免半个 JSON。

### 约束

- 标识只允许 `^[a-z0-9-]{1,64}$`。含路径分隔符的标识一律拒绝，读写两端都校验。
- 单个样式上限 512 KiB。
- 索引损坏（非法 JSON）时改名保留为 `presets.json.corrupt`，再按内置三预设重建。
- 删除选中项后自动选中列表第一项。删到列表为空时只重建默认预设 `lark`；另外两个经「恢复内置预设」补回。

### 迁移

0.1.0 之前的版本把选择存在 `settings.json`、覆盖样式存在 `custom.css`。首次读取时执行迁移：

1. 用内置样式写入三个预设文件。
2. 旧 `custom.css` 的内容追加到旧选择指向的预设末尾。
3. `selected` 取旧 `theme`；该值不是现存预设时回落到 `lark`。
4. 旧文件改名为 `settings.migrated.json` 与 `custom.migrated.css`，不删除。

验收标准：同一份样张在迁移前后导出，PDF 逐字节一致。实测 357,565 字节对 357,565 字节。

## 样式分层

导出页面的样式按固定顺序拼装：

1. 结构样式表：纸张、正文、标题、列表、表格、代码、图片、分页控制。
2. 预设样式表，以 `<style id="md2pdf-theme">` 插入。
3. 无第三层。用户改样式就是改预设本身。

预设 CSS 以文本插入，其中的 `</style` 会被转义，不能跳出样式块。

### 页面边距

`@page` 决定打印边距。基础样式表声明默认边距，预设可以覆盖，后声明者胜出——与打印引擎的层叠规则一致。

设置页的缩略图在屏幕上渲染，`@page` 不生效。缩略图生成时把生效边距回读出来，改写成 `body` 的内边距，这样缩略图能显示真实页边距。回读方法是取文档中最后一条 `@page { margin: ... }`。

### 三线表

两个国家标准预设使用三线表：顶线与底线 1.5pt，栏目线 0.75pt，无竖线，表头无底色。

渲染器识别表题与表注：紧挨表格上方、以「表 1」或「Table 1」开头的段落成为表题并居中；紧接表格下方、以「注：」「注:」「Note:」开头的段落成为表注。其余段落按普通段落处理。

### 中英分排

两个国家标准预设把中文与西文分开排。字体栈把拉丁字体放在前面，汉字自然回退到后面的中文字体：

```
"Times New Roman", Times, "FangSong", "仿宋", ...
```

代码块保持等宽字体。Times New Roman 不是等宽体，用在代码块会破坏缩进对齐。

## 渲染

Markdown 转 HTML 有两条通路。

内置渲染器（默认）实现 CommonMark 核心，加 GFM 表格、任务列表、删除线、自动链接，加脚注与 TeX 公式。不生成标题锚点 id，PDF 里用不到。

公式由 `temml` 转成 MathML，浏览器原生排版，不嵌入字体。temml 缺失时公式保留为等宽源码，其余内容不受影响。

pandoc 通路为可选：行配置 `renderer: pandoc` 时启用，读取器固定为 `gfm-emoji+tex_math_dollars`。选它是因为 pandoc 的 `markdown` 读取器拒绝紧贴段落下一行、中间没有空行的列表，与 DSH 里的渲染结果不一致。

### 列表识别

读取器按 CommonMark 规则识别：

| 写法 | 是否识别 |
|---|---|
| `- 项目`、`* 项目`、`+ 项目` | 识别 |
| `1. 项目`、`1) 项目` | 识别 |
| 列表紧接段落下一行，无空行 | 识别 |
| 列表紧接标题下一行 | 识别 |
| `1、项目` | 不识别，属中文编号习惯 |
| `（1）项目`、`①项目` | 不识别 |
| `· 项目`、`• 项目` | 不识别 |
| `-项目`，符号后无空格 | 不识别 |
| `*文字*` 整行 | 按强调处理 |

`scripts/diagnose-lists.mjs` 逐行报告后几类写法。

## 打印

打印器按顺序发现：

1. 宿主进程能加载 Electron 时，用 `BrowserWindow.printToPDF`，不启动第二个浏览器。
2. 否则用 Chromium 系浏览器无头模式 `--print-to-pdf`。查找顺序为 Edge、Chrome、Chromium、Brave。
3. 都不存在时返回 `no-printer`，界面给出提示。

### 落盘等待

打印进程退出早于文件写完。直接读目标文件会拿到半个 PDF，或者读到上一次的旧文件。

`src/pdf.js` 的 `awaitPdf()` 在启动打印前记录目标文件的大小与修改时间，之后轮询：文件存在、大小或时间戳变化、且尾部出现 `%%EOF` 才算完成。默认上限 20 秒。浏览器配置目录在落盘确认之后才清理。

### 失败码

失败统一由 `PdfError` 表达，路由映射为 HTTP 状态：

| 码 | 状态 | 含义 |
|---|---|---|
| `bad-request` | 400 | 参数非法 |
| `not-markdown` | 400 | 后缀不是 Markdown |
| `not-found` | 404 | 文件或预设不存在 |
| `not-a-file` | 400 | 路径不是文件 |
| `not-text` | 415 | 不是文本文件 |
| `too-large` | 413 | 超过上限 |
| `name-exists` | 409 | 预设重名 |
| `open-failed` | 500 | 打开文件失败 |
| `not-a-pdf` | 502 | 产物不是 PDF |
| `empty-output` | 502 | 产物为空 |
| `print-failed` | 502 | 打印失败 |
| `no-printer` | 503 | 无可用打印器 |

## 路由与安全

五条路由：

| 路由 | 方法 | 作用 |
|---|---|---|
| `/md2pdf/capability` | GET | 报告可用打印器 |
| `/md2pdf/export` | POST | 执行一次导出 |
| `/md2pdf/settings` | GET | 读预设库与选中预设的样式 |
| `/md2pdf/presets` | POST | 执行一个预设动作 |
| `/md2pdf/previews` | GET | 返回每预设一张缩略图页面 |

每条都在处理前调用 `ctx.connection.requestRejection()`。该检查校验 Host、Origin 与浏览器登录令牌，只有本机页面能触发。

请求体限定 `application/json`，大小有上限。

预设动作集中在一个分发器 `runPresetAction()`，路由只做鉴权与转换。动作包括 `read`、`select`、`save`、`order`、`delete`、`restore`、`open`。

### 打开文件

`open` 动作只接受索引里已知的预设标识。路径由标识拼出，并校验落在 `presets/` 内。客户端不能传路径。

Host 进程不是 Electron，没有 `shell` 可用。`src/opener.js` 按平台调系统程序：Windows 用 `cmd /c start "" <path>`，macOS 用 `open`，Linux 用 `xdg-open`。未知平台返回失败，不做猜测。

## 设置页交互

### 卡片

卡片分三块热区，悬停或键盘聚焦时出现：

- 上半部分：应用该预设。
- 下方 15%：蓝色横条，把该预设的 CSS 读进编辑器。
- 右上角：灰色圆角条，高约卡片 20%，点击弹出删除确认。

选中的卡片带蓝色描边。未改动的国标预设左上角显示「国标」标记；CSS 一旦与内置原文不同，标记消失。

### 保存语义

保存弹出名称对话框，默认值为当前编辑的预设名。

| 名称情况 | 行为 |
|---|---|
| 与当前预设相同 | 原地保存 |
| 与另一个预设相同 | 提示覆盖，确认后替换该预设的 CSS |
| 新名称 | 新建预设，追加到列表末尾 |

名称为空或全是空白时拒绝写入。

### 排序

上移、下移作用于当前编辑的预设，每次提交完整顺序。Host 校验提交的顺序是现有集合的一个排列，否则拒绝。排序只影响卡片顺序，不影响导出内容。

### 恢复

索引里缺少任一内置预设时，编辑器按钮行出现「恢复内置预设」。点击只补回缺失项，已有预设不动。

## 配置与常量

行配置：

| 字段 | 默认 | 作用 |
|---|---|---|
| `engine` | `auto` | 打印引擎：`auto`、`electron`、`browser` |
| `renderer` | `builtin` | 渲染器：`builtin`、`pandoc`、`auto` |
| `browserPath` | 空 | 显式指定浏览器 |
| `pandocPath` | 空 | 显式指定 pandoc |
| `timeoutMs` | 120000 | 打印超时 |

环境变量：

| 变量 | 作用 |
|---|---|
| `MD2PDF_HOME` | 预设库根目录，默认 `$DSH_HOME/md2pdf` |
| `MD2PDF_BROWSER` | 浏览器可执行文件 |

页面几何默认 A4、18 mm 页边距、15 px 正文。

## 已知限制

- 无页眉、页脚与页码。Chromium 命令行打印无法传入自定义页脚模板，GB/T 9704 要求的页码位、GB/T 7713.2 要求的页眉均未实现。
- 公文预设把一级标题渲染成红色小标宋并带红色分隔线，用来模拟红头。发文机关标志、发文字号、签发人、印章需要写在正文里，或用预设 CSS 补。
- 论文预设只落实可排版的部分：纸张、字体字号层级、缩进、三线表、图表题注位置。摘要、关键词、参考文献著录格式由作者按 GB/T 7714 写在正文中。
- 排序只影响卡片顺序。
- 「打开」依赖系统关联的默认程序。
- 相对图片依赖 `<base href>` 指向源文件目录。跨盘符的绝对 `file:` 引用可能被浏览器安全策略拒绝。
- 内置渲染器不生成标题锚点 id，也不支持 pandoc 特有的定义列表与 fenced div。
- PDF 覆盖同名文件，不保留历史版本。
